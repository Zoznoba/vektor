# Демо-данные

`demo_data.sql` — полный дамп базы (схема + данные) с двумя классами и их
результатами. Разворачивается в пустую базу одной командой, Alembic запускать
не нужно: `alembic_version` внутри дампа, ревизия `b9d41f7c2a08`.

```bash
make up                                    # Postgres + Redis
docker exec -i vektor-backend-db-1 psql -U vektor -d vektor < seed/demo_data.sql
uv run python seed/reset_demo_passwords.py # ОБЯЗАТЕЛЬНО, см. «Пароли» ниже
```

Если база не пустая — сначала пересоздайте её:

```bash
docker exec vektor-backend-db-1 psql -U vektor -d postgres \
  -c "DROP DATABASE vektor;" -c "CREATE DATABASE vektor;"
```

## Пароли — обязательный шаг

**Войти под демо-учёткой сразу после восстановления нельзя.** В дампе лежат
готовые argon2-хеши, посчитанные от `BULK_DEFAULT_PASSWORD` той машины, где дамп
снимали. `.env` в git не коммитится, у вас там другое значение, а хеш обратно не
разворачивается.

Поэтому после восстановления запустите `seed/reset_demo_passwords.py` — он
проставит всем живым учёткам ваш локальный `BULK_DEFAULT_PASSWORD`. Скрипт
идемпотентен. Служебные респонденты (`is_placeholder = true`) пропускаются: они
не логинятся в принципе.

## Что внутри

| | |
|---|---|
| Классы | 5-1 (12 учеников, 11 учителей), 8-1 (13 учеников, 14 учителей), 7-1 |
| Кампании | 5-1/2026, 8-1/2026 (редакция `2026.1`), 7-1/2025 (редакция `archive-2025`) |
| Анкеты | 112 |
| Ответы | 3360, шкала 1–5 |
| Справочник | 11 критериев, 5 «ОР / навык», 66 вопросов (две редакции) |

Класс 7-1 пустой намеренно: это снапшот под архивную кампанию 2025 года.
Ученики того состава сейчас учатся в 8-1, но видимость возрастных критериев
в 2025 считалась по 7 классу — поэтому у архивных анкет свой класс.

Пароль всех учёток — ваш локальный `BULK_DEFAULT_PASSWORD` из `.env`, но только
ПОСЛЕ прогона `seed/reset_demo_passwords.py` (см. «Пароли» выше).

Учётки на домене `@archive.vektor.ru` — служебные респонденты: в исходной
выгрузке педагоги и родители обезличены, ФИО там нет вообще, а `Assessment`
требует `respondent_id`. Один слот на (лист, роль, номер): «Педагог 2» у всех
учеников класса — один и тот же респондент, потому что правило анонимности
считает разных людей, а не строки. Они `is_active=false`, не привязаны к
классам и помечены `is_placeholder = true` — прав не дают. Флаг явный, а не
«угадывание по домену»: домен — это данные, и первый же реальный учитель с
похожей почтой попал бы под фильтр (миграция `b9d41f7c2a08`).

## Про персональные данные

**ФИО в дампе вымышленные.** Источник — реальная выгрузка школы, но все имена
учеников, родителей и учителей заменены при подготовке дампа; таблица
соответствия не сохранялась. Баллы, состав классов, связи родитель—ребёнок и
роли оценивающих — настоящие, поэтому демо ведёт себя как боевые данные.

Исходная выгрузка и списки из АИС «Электронный журнал» в репозиторий не
попадают (см. `.gitignore`).

## Особенности этих данных

* **Слоя «одноклассник» нет ни в одной кампании** — в исходной методике
  школы peer-оценки не собирались. Поэтому `peer_rater_count = 0` везде,
  порог анонимности (3 разных одноклассника по каждому критерию) не
  срабатывает, и баннер «оценки одноклассников скрыты» виден всегда. Это
  свойство данных, а не дефект.
* **Покрытие родителями низкое** — 4 анкеты на 12 учеников в 5-1 и 4 на 13
  в 8-1. У большинства субъектов слой parent пустой.
* **Критерий «Исследование профессиональных возможностей» пуст** у 5 и 8
  классов: он открывается с 9-го (`min_grade = 9`).
* **История есть только у 8-1** — кампания 7-1/2025. У пятиклассников
  прошлогодних данных нет, сравнивать по годам не с чем.
