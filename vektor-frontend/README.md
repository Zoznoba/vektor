# Вектор — фронтенд платформы (React + TypeScript)

Стек: React 19 + TypeScript + Vite (Вариант А из ТЗ, раздел 6.2).

## Запуск

```bash
npm install
npm run dev      # дев-сервер
npm run build    # прод-сборка + проверка типов
```

## Структура

```
src/
  styles/
    tokens.css        # все цвета, радиусы, шрифты — переменные CSS. Менять только здесь.
    global.css        # сброс стилей, базовые правила body/h1-h3, фокус, reduced-motion
  components/
    icons/Icon.tsx     # линейные SVG-иконки (без внешних иконных библиотек)
    ui/                # атомы: Button, Badge, ProgressBar, Avatar, Panel
    layout/             # Topbar, Sidebar, AppShell — каркас личного кабинета
    dashboard/          # элементы конкретно для главной ученика: баннер, карточки
  data/
    navigation.ts        # состав пунктов сайдбара (сейчас зафиксировано 4 пункта для ученика)
    mockStudentDashboard.ts # тестовые данные — заменяются на реальный API-вызов
  types/
    dashboard.ts          # типы данных главной страницы
  pages/
    student/StudentHome.tsx # Экран 1 из ТЗ (п. 4.7) — единственная готовая страница
```

## Дизайн-система

Токены в `src/styles/tokens.css` совпадают 1:1 с утверждённым UI-китом
(`vektor-platform-design.html`). Источник — реальная айдентика
vektor.school (логотип + Tilda-стили), адаптированная под рабочий
интерфейс: лайм и тёмный сайдбар — единственные «громкие» элементы,
остальное — спокойные карточки на тёплом фоне.

Шрифты: Jost (заголовки/цифры, замена недоступного по лицензии
FuturaPT той же геометрической природы) + Manrope (текст/данные,
читаемее на мелком кегле). Подключены через Google Fonts в `index.html`.

`--topbar-h: 64px` и `--sidebar-w: 218px` — уточнённые значения
относительно черновика в ТЗ (46px / 152px), сделано из-за того, что в
исходных размерах логотип и подписи пунктов меню не помещались.
Стоит сверить с командой до начала остальной вёрстки — если узкий
сайдбар принципиален, оба значения вынесены в одно место (tokens.css).
